# 装甲板检测练习项目

这是配合浙大 Hello World 视觉组《Git & GitHub 教学》使用的练习项目
zheshi。

## 文件结构

- `src/armor_detector.cpp` / `src/armor_detector.h` —— 装甲板检测器示例代码（教程里反复出现的文件就是它）
- `src/main.cpp` —— 程序入口
- `CMakeLists.txt` —— 构建配置
- `build/`、`dataset/`、`run.log`、`.vscode/` —— 故意放的"垃圾文件"，练习 4 里用 `.gitignore` 处理它们

跟着《Git 练习单》一步一步来，每个练习都对应教程的一个小节。
